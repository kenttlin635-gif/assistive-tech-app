# 身障輔具 & 無障礙補助查詢系統 (PWA 離線強化版)

一個專為輔具評估人員與社工打造的輕量化、無伺服器（Serverless）查詢工具。本系統整合了 **Google 試算表自動同步**與 **PWA 全離線快取技術**，即使在沒有行動數據或 Wi-Fi 的無網路環境下（如地下室、深山案家），依然能秒開並正常查詢最新補助基準。

👉 **[點此線上使用系統](https://kenttlin635-gif.github.io/assistive-tech-app/)**

---

## 🚀 核心特色 (Key Features)

- **🌐 100% 離線運作**：利用 Service Worker (`sw.js`) 與 `LocalStorage` 雙層防護機制，將前端核心套件（React, Tailwind）與歷史資料快取至裝置硬碟。沒網路時自動開倉取用，達成完全離線查詢。
- **🔄 自動化資料同步**：透過 GitHub Actions 建立定時排程（Cron Job），每天午夜自動從 Google Sheets 下載最新的 CSV 資料並更新，免去手動上傳的麻煩。
- **🧹 智慧資料清洗**：前端內建映射邏輯，自動將 CSV 中零散的子分類（如：視覺、聽覺相關）智慧統整至「**溝通及資訊輔具**」大分類下。
- **📱 極致響應式 UI (RWD & UX)**：
  - **手機版**：單行精煉 Header，釋放側邊欄操作空間，金額卡片採純白底色大字體，閱讀不費力。
  - **電腦版**：寬度最大化（`max-w-7xl`），年限、人員、三種戶別金額整合成 5 欄式高效資訊列。
- **🎨 精緻細節**：背景垂直置中淡綠色項次大浮水印、標題內建「項次. 項目名稱」前綴、搜尋欄一鍵清除（X）按鈕、選中項目變色高亮。

## 📲 安裝方式 (Installation)

本系統支援 PWA (Progressive Web App) 技術，不需透過 App Store 或 Google Play，即可直接將網頁「下載安裝」至手機桌面，像原生 App 一樣秒開且隱藏瀏覽器網址列。

### 🍏 iOS 裝置 (iPhone / iPad)
1. 使用 **Safari 瀏覽器** 開啟本系統網頁。
2. 點擊瀏覽器底部工具列的 **「分享」按鈕**（一個正方形箭頭朝上的圖示）。
3. 在選單中向下滑動，點選 **「加入主畫面」** (Add to Home Screen)。
4. 確認名稱後點擊右上角的「新增」，App 圖示即會出現在手機桌面上。

### 🤖 Android 裝置 (三星、小米、Pixel 等)
1. 使用 **Google Chrome 瀏覽器** 開啟本系統網頁。
2. 點擊網址列右側的 **「三個點」選單按鈕**。
3. 在選單中點選 **「安裝應用程式」** 或 **「加入主畫面」**。
4. 依系統提示完成安裝，即可在桌面與應用程式抽屜中找到 App。

### 💻 電腦端 (Windows / Mac)
1. 使用 Chrome 或 Edge 瀏覽器開啟網頁。
2. 觀察網址列右側，會出現一個 **「視窗加網格」的安裝圖示**（或在選單中選取「安裝此網站為應用程式」）。
3. 安裝後即可擁有獨立的視窗視窗運行本系統。

## 🔄 更新方式 (Updates)

系統的更新區分為「資料面」與「程式功能面」，兩者皆具備自動化與快取重置機制。

### 1. 補助資料更新 (對使用者/小編)
- **雲端同步**：只要你在 Google 試算表修改內容，每天午夜 GitHub Actions 就會自動抓取最新資料。
- **用戶端接收**：當小編或社工在**有網路**的狀態下開啟 App，系統就會在背景偷偷下載最新資料，並自動覆蓋掉手機舊的本地離線備份。之後就算走到斷網環境，查到的也都會是這批最新資料。

### 2. 程式碼與 UI 介面更新 (對開發者)
由於 Service Worker 的離線快取控制非常嚴格，如果你修改了 `index.html` 的排版或 `sw.js` 的程式邏輯，使用者的手機往往會因為「死守舊快取」而看不到新介面。
* **強制重置快取機制**：修改完代碼後，請打開 `sw.js`，將最上方的 `CACHE_NAME` 版本號進行遞增變更（例如：將 `const CACHE_NAME = 'assistive-tech-v3';` 改為 `v4`）。
* **生效原理**：當使用者的手機偵測到 `sw.js` 檔案內容變動，就會自動在背景觸發重新下載，並在下一次重啟 App 時全面強制換成最新版網頁。

## 🛠️ 技術棧 (Tech Stack)

- **核心架構**：React 18 (透過 CDN 載入，具備離線快取)
- **樣式編寫**：Tailwind CSS (響應式切版與即時樣式控制)
- **資料解析**：PapaParse (輕量級 CSV 解析器)
- **即時編譯**：Babel Standalone
- **部署環境**：GitHub Pages (Serverless 靜態網頁託管)
- **自動化流**：GitHub Actions + Google Sheets API (`pub?output=csv`)
